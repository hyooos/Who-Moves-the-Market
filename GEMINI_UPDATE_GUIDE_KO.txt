Gemini AI 연결 업데이트
======================

수정 내용
- gemini-1.5-flash를 정식 gemini-3.6-flash로 교체했습니다.
- 구형 google-generativeai 대신 공식 google-genai SDK를 사용합니다.
- AI 설정에 실제 Gemini 요청을 보내는 '실제 연결 테스트' 버튼을 추가했습니다.
- API 키가 입력돼 있어도 테스트 호출에 성공하기 전에는 '연결됨'으로 표시하지 않습니다.
- API 키 또는 모델을 바꾸면 새 설정 토큰을 사용해 이전 번역 실패 캐시를 재사용하지 않습니다.
- 원문 번역, 사건 요약 생성, 데이터 질문이 같은 provider·모델·API 키를 사용합니다.
- run_streamlit.bat과 run_streamlit.sh는 google-genai가 없으면 requirements-dashboard.txt를 통해 설치합니다.

사용 방법
1) 실행 중인 Streamlit 창에서 Ctrl+C를 눌러 종료합니다.
2) 수정 파일을 service-v2 최상위 폴더에 덮어씁니다.
3) Windows에서는 run_streamlit.bat을 다시 실행합니다.
4) 화면 오른쪽 위 'AI 설정'을 열고 Gemini를 선택합니다.
5) Gemini API 키를 입력하고 모델이 gemini-3.6-flash인지 확인합니다.
6) '실제 연결 테스트'를 누릅니다.
7) '연결됨 · gemini-3.6-flash'가 나타난 뒤 번역·요약·데이터 질문을 사용합니다.

상태 표시 의미
- 연결됨: 현재 키와 모델로 실제 짧은 Gemini 호출에 성공했습니다.
- 확인 필요: 키 또는 모델이 준비됐지만 아직 테스트하지 않았거나 설정이 바뀌었습니다.
- 연결 실패: 인증, 모델, 사용 한도, 네트워크 등의 이유로 실제 호출에 실패했습니다.
- 연결 안 됨: AI 서비스를 사용하지 않는 상태입니다.

주의
- API 키는 코드나 결과 CSV에 저장하지 않고 Streamlit 실행 중 환경변수로만 전달합니다.
- 무료/유료 사용 한도와 과금 정책은 API 키가 속한 Google 프로젝트의 정책을 따릅니다.
- 전체 데이터 분석 파이프라인은 다시 실행할 필요가 없습니다. 이번 변경은 Streamlit AI 기능과 실행 의존성 변경입니다.
