# Who Moves the Market? 코드·고도화 가이드

## 지금 프로그램이 하는 일

이 프로젝트는 게시물 내용을 보고 미래 주가를 맞히는 예측기가 아닙니다. 과거 게시물을 시장 시간축에 정확히 놓고, 그 직후 실제 가격·거래량·변동성이 평소보다 얼마나 이례적이었는지 측정하는 회고적 이벤트 스터디입니다.

데이터 흐름은 다음과 같습니다.

`원본 CSV → 공통 스키마 → 시장 관련 게시물 → ET 거래일 정렬 → 가격 반응 계산 → 오염 분류 → 통계검정 → 리포트/대시보드`

이번 시간 정렬 수정부터는 원본 UTC 시각을 미국 동부시간으로 바꿉니다. 거래일 16:00 이후 게시물과 주말·휴장일 게시물은 다음 실제 거래일에 연결합니다. 장중 게시물은 당일 일봉에 연결하지만 게시 전 움직임도 섞이므로 `PARTIAL_DAY_INTRADAY_PREFERRED`라는 경고를 남깁니다.

| 병목 | 현재 원리 | 개선 방향 |
| --- | --- | --- |
| 원본 CSV 전처리 | 실행할 때마다 12만 건 이상을 읽고 문자열 규칙을 다시 적용 | 입력 파일 해시를 키로 Parquet 캐시 |
| 가격 다운로드 | yfinance 네트워크 응답과 티커별 다운로드 대기 | 날짜 증분 업데이트 + 실패 재시도 + 영구 캐시 |
| 감성·novelty | 각 게시물에 모델 추론 또는 임베딩 계산 | 배치 추론, 결과 캐시, 신규 행만 계산 |

## 고도화 로드맵

### 1. 데이터 신뢰성

- 완료: 입력 중복 방어, 원본 URL/ID 보존, UTC/ET 명시, 장후·휴장일 다음 거래일 정렬, 6시간 사건 clustering, 회귀 테스트.
- 다음: 조기폐장까지 지원하는 NYSE 거래소 캘린더, 실제 FOMC 전체 달력, topic 수동 라벨 200건 이상.
- 완료 기준: 같은 입력으로 언제 실행해도 같은 이벤트 수와 날짜가 나오고, 표본 추적이 원문까지 가능해야 합니다.

### 2. 클릭형 사건 분석

- 차트 한 점을 클릭하면 원문, 한국어 번역, 근거가 분리된 요약, 시장 해석, 전후 가격 차트를 한 패널에 표시합니다.
- 일봉은 2025-04까지 자동 분석하고, 장중 표본과 대표 사건은 분봉 데이터를 우선 사용합니다.
- LLM 문장은 `관측 사실 / 가능한 해석 / 확인 불가`로 나눠 인과관계 과장을 막습니다.

### 3. 실제 도움이 되는 질문형 분석기

- 자유 질문을 먼저 `필터·집계 질문`, `특정 사건 질문`, `방법론 질문`, `최신 뉴스 질문`으로 분류합니다.
- 숫자는 LLM이 만들지 않고 pandas/SQL 도구가 계산하며, LLM은 계산 결과만 설명합니다.
- 답변마다 사용 이벤트 수, 기간, 오염 필터, ticker, 원문/기사 근거를 표시합니다.
- 대화 기억에는 사용자의 현재 필터와 비교 대상만 저장해 “아까 그 사건과 비교해줘”가 작동하게 합니다.

### 4. 2025-04 이후 실시간 레이어

- 게시물/뉴스 수집과 영향 분석을 분리합니다. 새 글은 즉시 `관심 알림`만 제공하고 가격 반응은 장 종료 후 확정합니다.
- 1차: 뉴스·게시물 수집, 중복 기사 묶기, 한국어 요약.
- 2차: 장 종료 뒤 실제 가격 반응 업데이트.
- 3차: 다음 거래일 뒤 CLEAN 여부와 통계 비교 업데이트.
- 날짜만 알려진 사건과 정확한 게시 시각이 확인된 사건을 구분하고, 검증되지 않은 시각은 가격 정렬 근거로 과장하지 않습니다.

### 5. 속도·운영

- CSV 산출물은 사용자 다운로드용으로 유지하되 내부 캐시는 Parquet/DuckDB로 전환합니다.
- 감성·임베딩·기사·LLM 결과를 콘텐츠 해시로 캐시하고 신규 데이터만 계산합니다.
- 데이터 파이프라인, LLM 작업, 화면 앱을 분리해 한 부분의 실패가 전체 실행을 막지 않게 합니다.
