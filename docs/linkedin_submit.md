### 프로젝트 [누가 시장을 움직이는가? : 트럼프·일론 머스크 SNS 게시물 기반 주가 반응 분석]

## 1. 프로젝트 주제

### 프로젝트 배경과 해결하고자 한 문제

도널드 트럼프와 일론 머스크는 정책·기업·기술·시장에 관한 메시지를 SNS에 직접 게시하며, 실제로 시장 가격과 투자자 심리에 영향을 줄 수 있는 대표적인 인물입니다. 그러나 게시물 직후 주가가 움직였다는 사실만으로 해당 발언이 가격 변동의 원인이라고 단정하기는 어렵습니다. 같은 날의 거시경제 뉴스, FOMC, 다른 게시물, 시장 전체 충격이 함께 발생할 수 있고, 같은 반응을 여러 게시물에 중복해서 세면 통계적으로 유의한 것처럼 보이는 문제가 생깁니다.

이 프로젝트는 Truth Social/X 게시물과 금융시장 데이터를 미국 동부시간(ET) 기준으로 정렬하고, 게시물 직후 가격·거래량·변동성이 평소보다 이례적이었는지를 이벤트 스터디로 검증했습니다. 목표는 미래 주가를 예측하거나 투자 신호를 만드는 것이 아니라, 다음 질문에 답하는 것입니다.

- SNS 게시물 이후 시장 반응이 평소의 변동 범위를 벗어났는가?
- 주제(topic)에 따라 반응 크기가 달라지는가?
- 머스크와 트럼프의 게시물 반응에 차이가 있는가?
- 게시물의 감성, 참여도, 새로움이 반응 크기와 관련이 있는가?
- 관찰된 차이가 실제 인물·주제 효과인지, 종목(ticker)별 변동성 차이 때문인지 구분할 수 있는가?

AI와 데이터 분석을 활용한 이유는 대규모 텍스트를 일관된 기준으로 정제·분류하고, 게시 시각과 거래일을 정확히 연결하며, 가격·거래량·변동성을 정량적으로 비교하기 위해서입니다. 수치 계산은 Python과 통계 검정으로 수행하고 AI는 번역·요약·질문형 설명에 제한했습니다.

## 2. 프로젝트 진행 과정

### 데이터 및 분석 환경

- **데이터**: Kaggle Trump 게시물(`Kaggle_Trump_2009_2025.csv`), Musk X 게시물(`all_musk_posts.csv`), `yfinance` 일봉 OHLCV, FOMC 일정, Google News RSS·기사 출처
- **주요 데이터**: 원문, 게시물 ID·URL, 작성자, 플랫폼, 게시 시각, 참여도, topic, ticker, Trump 역할, 감성 레이블·점수, novelty score, 수익률, 초과수익률, 변동성, 거래량
- **규모**: 원본 127,246건(Trump 90,343건, Musk 36,903건) → 시장 관련 3,015건(Musk 1,507건, Trump 1,508건) → 6시간 clustering 후 Track1 사건 2,173건 → CLEAN 429건 정식 검정. Track2 뉴스·수동 검증 사례 6건을 추가해 총 2,179건을 대시보드에 제공
- **기간**: Track1 2023-01-03~2025-04-13, Track2 확장 범위 2025-10-23까지
- **환경과 도구**: Python, Pandas, NumPy, SciPy, statsmodels, scikit-posthocs, yfinance, Plotly, Jinja2, Requests, Streamlit
- **선택 기술**: PyTorch, Hugging Face Transformers의 Twitter-RoBERTa, Ollama/Qwen, Gemini·Groq 연동

### 데이터 분석 및 전처리

1. 서로 다른 CSV 구조를 공통 스키마로 통합하고, 중복 파일·중복 게시물과 분석 목적에 맞지 않는 Musk의 짧은 답글을 제거했습니다. 원본 ID와 URL은 최종 이벤트까지 보존했습니다.
2. 시장·기업·정책·기술 키워드를 단어 경계 기준으로 적용해 시장 관련 게시물을 필터링했습니다. `ai`, `autonomy_robotaxi`, `china`, `tariff`, `trade_policy`, `tesla_business` 등의 topic을 룰 기반으로 분류하고 TSLA·QQQ·SPY를 연결했습니다.
3. UTC 시각을 ET로 변환하고, 장 시작 전은 같은 거래일, 장 마감 후·주말·휴장일은 다음 실제 거래일에 연결했습니다. 장중 게시물은 게시 전 움직임이 섞일 수 있다는 품질 경고를 남겼습니다.
4. 같은 화자·ticker·topic·반응 거래일의 게시물을 첫 게시물 기준 6시간 창으로 묶어 동일한 가격 반응을 반복해서 세는 pseudo-replication을 줄였습니다.
5. 가격 데이터 결측 이벤트는 검정 대상에서 제외하고, FOMC·다중 게시·시장 전체 충격의 중첩 여부를 계산했습니다. CLEAN·MINOR·MAJOR로 오염을 분류하고 CLEAN만 정식 가설검정에 사용했습니다.
6. 종목 수익률에서 시장 또는 peer 평균을 차감한 초과수익률, 최근 60거래일 중앙값·MAD 기반 robust z-score, `impact_score = |z_ar| + max(z_volume, 0) + max(z_volatility, 0)`를 생성했습니다. 선택 기능으로 Twitter-RoBERTa 감성과 과거 문장 유사도 기반 novelty score도 계산했습니다.
7. 본 분석은 미래 예측용 지도학습이 아닌 과거 사건 검정이므로 train/validation/test 분할은 적용하지 않았습니다. 대신 ticker 통제, FDR 보정, 200회 placebo 순열검정, RIVN peer 민감도 분석으로 결과의 견고성을 확인했습니다.

### AI / 모델링 과정

- 이벤트 스터디와 robust z-score를 사용해 극단값에 덜 민감한 사건 반응을 측정했습니다.
- 분포의 정규성을 가정하기 어려워 Wilcoxon, Kruskal-Wallis, Mann-Whitney, Spearman 비모수 검정을 사용했습니다.
- 여러 가설을 동시에 검정하므로 Benjamini-Hochberg FDR 보정을 적용했습니다.
- 키워드 규칙 기반 NLP로 시장 관련성·topic·ticker를 분류하고, Twitter-RoBERTa로 선택적 감성분석, 문장 유사도로 novelty score를 계산했습니다.
- Google News RSS 수집 후 사건 단위로 clustering하는 Track2 파이프라인을 구축했습니다.

생성형 AI는 원문 번역, 사건 요약, 데이터 질문에 대한 자연어 설명을 담당합니다. 등락률·z-score·표본 수·검정 결과는 pandas와 통계 모듈이 계산한 값을 사용하며, AI가 임의의 수치를 생성하지 않도록 분리했습니다. Gemini·Groq·Ollama 연결에 실패하면 원문과 계산값 기반 기본 요약으로 fallback하고, 근거가 부족한 Track2 사례는 “판단보류”로 표시합니다.

## 3. 결과 및 평가

현재 산출물의 CLEAN 429건 기준 결과입니다. p-value는 다중검정 보정 결과와 함께 해석했습니다.

| 가설 | 검정 결과 | 결론 |
| --- | --- | --- |
| H1 | 게시 전후 변동성 Wilcoxon: p=0.225, FDR p=0.361 | 유의한 변동성 증가 확인 실패 |
| H2 | topic별 절대 초과수익률 Kruskal-Wallis: p=1.38×10⁻²⁹, FDR p=2.21×10⁻²⁸ | 전체 비교에서는 유의 |
| H2 보조 | ticker 고정 후 QQQ p=0.057, SPY p=0.152, TSLA p=0.807 | ticker 고정 시 유의하지 않음 |
| H3 | Musk·Trump 반응 Mann-Whitney: p=4.59×10⁻¹¹, FDR p=3.67×10⁻¹⁰ | 전체 비교에서는 유의 |
| H3 보조 | QQQ로 ticker 고정 후 p=0.561, FDR p=0.673 | 독립적인 인물 효과 확인 실패 |
| H4 | 참여도·절대 초과수익률 Spearman: p=0.589 | 유의한 상관 확인 실패 |
| 감성 탐색 | 긍정·부정 비교 FDR p=0.0129, 감성 점수 상관 FDR p=0.0129 | 탐색적 유의성은 있으나 인과 해석 불가 |
| novelty 탐색 | Spearman p=0.0525, FDR p=0.131 | 유의하지 않음 |
| placebo | 200회 순열에서 실제보다 같거나 더 유의한 H2·H3 비율 0% | 무작위 날짜만으로 재현되지 않음 |

전체 표본에서 topic과 인물 차이는 매우 크게 나타났지만 ticker를 고정하면 유의성이 사라졌습니다. ticker가 절대 초과수익률 분산의 약 27.2%를 설명했고, topic이 추가로 설명하는 비중은 약 0.3%p였습니다. 따라서 “특정 topic이나 인물이 시장을 더 움직인다”는 해석은 종목 구성에 의한 교란으로 재해석해야 합니다.

검증 과정에서는 SPY를 자기 자신과 시장 벤치마크로 비교하던 오류와 `ai`가 `said` 내부에서도 매칭되던 단어 경계 오류를 수정했습니다. 후자의 수정으로 시장 관련 게시물은 6,185건에서 3,015건으로 감소했습니다. Track2에서는 2025-10-10 관세 발표의 SPY z-score가 -5.49로 확장 기간의 최대 반응 중 하나였습니다. 이 결과는 시간적 연관이지 인과관계의 증명은 아닙니다.

### 서비스 구현

분석 결과를 Streamlit 대시보드로 제공했습니다.

- **시장 반응**: TSLA·QQQ·SPY별 반응 게이지, 주가·사건 타임라인, Musk·Trump 구분, 원문·감성·전후 가격
- **사건 찾기**: 인물, ticker, 자료 형태, topic, 감성, 키워드 필터와 사건 상세
- **데이터 질문**: 반응이 가장 컸던 사건, 인물 비교, 시장별 비교, 감성별 비교, 사건 수·기간 집계
- **AI 보조**: 사건 요약, 영어 원문 한국어 번역, 자연어 데이터 설명. AI 키 없이도 기본 기능과 계산 결과 제공
- **최신 조회**: 비공식 Truth Social 미러 RSS와 Jina Reader로 Trump 최신 게시물을 조회하되, 가격 반응 확정 전에는 예측값이 아닌 관심 알림으로만 표시
- **산출물**: CSV 이벤트 테이블, JSON 통계, Plotly HTML 차트 4종, HTML 리포트

## 4. 주요 인사이트 또는 배운점 / 개선 방향

### 주요 인사이트

1. 게시물 직후 시장이 움직였다는 사실과 그 반응이 topic·화자 때문에 발생했다는 주장은 분리해서 검증해야 합니다.
2. 종목의 기본 변동성이 다르면 topic이나 인물 효과처럼 보이는 차이가 생깁니다. 이번 분석에서는 ticker 통제 전 유의했던 H2·H3가 통제 후 사라졌습니다.
3. 같은 날 여러 게시물을 독립 사건으로 세면 동일한 가격 반응을 반복 관측하게 되므로 6시간 clustering이 필요했습니다.
4. 규칙 기반 NLP는 빠르고 설명 가능하지만 문맥에 취약합니다. 직접 라벨링한 정확도 56%는 자동 분류 결과를 그대로 사실로 받아들이면 안 된다는 점을 보여줍니다.
5. 데이터 품질 검증에서 benchmark 오류와 키워드 경계 오류를 발견한 경험을 통해, 유의한 결과보다 분석 파이프라인 검증이 먼저라는 점을 확인했습니다.

### 배운 점과 한계

- UTC·ET와 장전·장중·장후·휴장일을 구분하지 않으면 게시물과 가격 반응의 연결 자체가 달라질 수 있음을 배웠습니다.
- robust 통계량, 오염 분류, placebo, FDR, 효과크기, 교란 통제를 함께 사용해야 p-value 이상의 설명이 가능했습니다.
- 일봉 데이터로는 장중 선후관계와 반응 지속시간을 충분히 보여주기 어려워 H5는 판단을 보류했고, 대표 사건용 분봉 분석 스크립트를 별도로 제공했습니다.
- 관찰자료 기반 분석이므로 SNS 발언과 가격 변화의 인과관계를 증명하지 않습니다. CLEAN은 인과성이 아니라 확인 가능한 주요 오염을 줄였다는 뜻입니다.
- Trump 대통령 시기 표본은 9건으로 작고, Google News RSS는 모든 관련 기사를 보장하지 않습니다. Musk는 안정적인 무료 실시간 X 수집원이 없어 실시간 조회 대상에서 제외했습니다.

### 개선 방향

- topic 수동 라벨을 200건 이상으로 확대하고 문맥을 반영하는 다중 라벨 모델과 룰 기반 결과를 비교하겠습니다.
- NYSE 거래소 캘린더와 조기폐장 정보를 적용하고, 장중 게시물은 1분·5분 단위 분봉 이벤트 스터디로 확장하겠습니다.
- 시장·산업·정책 요인을 통제하는 회귀 또는 matched-event 설계를 추가해 ticker 교란과 날짜별 공통 충격을 더 엄밀히 분리하겠습니다.
- 게시물·기사·감성·임베딩·LLM 결과를 콘텐츠 해시로 캐시해 새 데이터만 증분 처리하겠습니다.
- 실제 서비스에서는 데이터 출처와 원문 링크의 지속성, API·RSS 장애 대응, AI 요약의 근거 표시, 투자 조언으로 오인되지 않는 안내를 관리하겠습니다.
