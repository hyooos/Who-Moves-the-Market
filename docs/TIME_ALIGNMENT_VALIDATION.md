# UTC/ET 거래일 정렬 검증 기록

검증 입력은 사용자가 제공한 Musk·Trump 원본 CSV와 중복이 제거된 기존 baseline 결과입니다.

## 결과

| 항목 | 결과 |
| --- | ---: |
| Track1 시장 관련 이벤트 | 3,015건 |
| 원본 게시물 ID 보존 | 3,015 / 3,015 |
| 원문 URL 보존 | 3,015 / 3,015 |
| 기존 날짜와 달라진 이벤트 | 438건(14.5%) |
| 날짜가 달라진 세션 | 전부 장 마감 후 게시물 |
| 중복 원본을 두 번 넣은 방어 테스트 | 127,246건 중복 자동 제거 |

이벤트 거래일 이동 폭은 `+1일 342건`, `+2일 4건`, `+3일 83건`, `+4일 9건`입니다. 주말과 연휴 때문에 3~4일 이동하는 경우가 생깁니다.

새 시장 세션 분류는 `휴장일 896건`, `장후 834건`, `정규장 768건`, `장전 517건`입니다. 정규장 768건은 당일 일봉에 게시 전 가격 움직임도 섞일 수 있어 `PARTIAL_DAY_INTRADAY_PREFERRED`로 표시합니다.

## CLEAN 표본 변화

| contamination 수준 | 수정 전 | 수정 후 |
| --- | ---: | ---: |
| CLEAN | 359 | 357 |
| MINOR | 2,289 | 2,304 |
| MAJOR | 367 | 354 |

총 93건의 contamination 수준이 달라졌습니다.

- `MAJOR → MINOR`: 48건
- `MINOR → MAJOR`: 35건
- `CLEAN → MINOR`: 6건
- `MINOR → CLEAN`: 4건

따라서 README의 기존 가설검정 수치는 새 코드로 전체 파이프라인을 다시 실행한 뒤 갱신해야 합니다. 이번 검증은 시간 정렬과 표본 구성이 달라지는 규모를 확인한 것이며, 수정 후 H1~H6 결과를 미리 단정하지 않습니다.

## 통과한 검사

- 겨울/여름 서머타임, 장전, 장중, 장후, 금요일 장후, 주말, 7월 4일 휴장 회귀 테스트

- 입력 파일 중복 방어 테스트
